# AngelBite

Статический сайт — сервер, Node.js и API-ключи не нужны.

- Открой `index.html` двойным щелчком или залей папку на GitHub Pages / Netlify / любой хостинг.
- Картинки встроены прямо в `index.html` (WebP). Папка `assets/` — только оригиналы, сайт на неё не ссылается.
- Ресурс-паки лежат в `packs/` (7 файлов) и скачиваются прямо с сайта; моды — ссылки на Modrinth.
- Игры: `fnaf.html` и `bitecrew.html` должны лежать рядом с `index.html`.

## Секреты
- Konami-код (↑ ↑ ↓ ↓ ← → ← → B A) вызывает крипера.
- 5 кликов по подвалу — секретное достижение.
- Достижения запоминаются в браузере (localStorage).

## Экономика аккаунта
- Кристаллы выдаются за регистрацию, голосование и ежедневный сундук. Серия входов повышает награду; каждый седьмой день даёт бонус.
- Рубины выдаёт только администрация. Прайс PLUS / PRIME / ECLIPSE в ⭐ показан в профиле; онлайн-списание звёзд пока не подключено.
- Подробные составы привилегий находятся в `public/account.html`; выдача на Minecraft-сервере выполняется администрацией вручную.
- Для уже созданной D1-базы перед деплоем новой версии примени миграции `migrations/0002_daily_claims.sql` и `migrations/0003_profile_stickers.sql`.
